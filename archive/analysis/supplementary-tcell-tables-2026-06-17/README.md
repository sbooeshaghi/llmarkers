# Supplementary T-cell Tables Archive

This archive contains scripts and LaTeX table files that previously generated
Supplementary Tables S5 and S6:

- `tables/tcell_marker_clusters.tex`
- `tables/tcell_gene_f1_ratios.tex`
- `scripts/build_tcell_marker_cluster_latex_table.py`
- `scripts/build_tcell_gene_f1_latex_table.py`

The tables were removed from the active manuscript on 2026-06-17 because they
were no longer doing necessary work for the paper's current CAP- and
formalization-centered argument. Related T-cell/old Figure 5 generation scripts
are kept here rather than deleted so the analysis can still be inspected or
restored if needed.

The generated result TSVs in `analysis/results/` were intentionally left in
place because other audit reports and prototype scripts may still read them.
