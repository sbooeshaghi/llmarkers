# Paper Figure Manifest

This file records the current paper-facing figure pipeline. It is meant to keep
the repository clean while preserving the source scripts needed to regenerate
the manuscript figures and supplementary tables.

## Current Manuscript Dependencies

`paper/src/main.tex` currently uses:

| Role | Paper reference | Artifact | Source |
| --- | --- | --- | --- |
| Conceptual Figure 1 | `fig:paper_celltype_joint` | `paper/src/figures/fig_paper_celltype_joint.tex` | `docs/fig1.md` |
| Figure 2 | `fig:marker_selection`, `fig:llm_curation` | `analysis/figures/fig_marker_recovery.pdf` | `analysis/build_fig2_marker_recovery.py` |
| Figure 3 | `fig:cross_study_unification` | `analysis/figures/fig3_local_global_marker_identifiability.pdf` | `analysis/build_fig3_local_global_marker_identifiability.py` |
| Supplementary Hildreth figure | `fig:hildreth_detail` | `analysis/figures/fig_hildreth_detail.pdf` | `analysis/lfc_comparison.ipynb` |
| Supplementary T-cell cluster table | `tab:tcell_marker_clusters` | `paper/src/tables/tcell_marker_clusters.tex` | `analysis/build_tcell_marker_cluster_latex_table.py` |
| Supplementary T-cell gene F1 table | `tab:tcell_gene_f1_ratios` | `paper/src/tables/tcell_gene_f1_ratios.tex` | `analysis/build_tcell_gene_f1_latex_table.py` |

Standalone poster/slide wrappers are kept in
`paper/src/figures/standalone/`. Run
`scripts/render_paper_standalone_figures.sh` from the repository root to render
the standalone PDFs into `paper/src/figures/standalone/build/`.

## Figure Structure

1. **Figure 1: marker claims are underspecified by labels alone.**
   The TikZ figure gives the conceptual setup: paper-level marker profiles can
   agree or disagree by cell type label and marker genes.

2. **Figure 2: benchmark and LLM recovery.**
   The benchmark summary, DEG-rank recovery analysis, and LLM curation
   comparison are generated by `analysis/build_fig2_marker_recovery.py`.

3. **Figure 3: local and global marker definitions.**
   The figure shows why local marker separation within papers does not imply
   global cell type definitions across papers, then quantifies the effect in
   the extracted marker corpus.

## Cleanup Rules

- Do not delete raw paper markdown, marker JSON, metrics, metadata, or reviewed
  context/evidence files.
- Generated prototype figures not referenced by `main.tex` are ignored in
  `.gitignore`.
- `analysis/cross_study_gene_space.py` is part of the active source pipeline
  and should be tracked.
- Text edits come after the figure structure is stable.
