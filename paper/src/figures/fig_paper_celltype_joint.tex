\caption{\textbf{Marker-profile comparisons expose label-marker ambiguity.} Reported marker claims are aggregated into paper-celltype profiles: one paper, one reported cell type label, and a set of mapped marker gene IDs. The example uses extracted human T-cell profiles selected to illustrate common cross-study relationships: the same label with the same, overlapping, or disjoint markers; related labels with identical or overlapping markers; and different labels with overlapping markers \cite{SadeFeldman2018,Krishna2021ccrcc,LopezCobo2024,Wu2026,Schafflick2020ms,Dominguez2022celltypist,Egozi2023nec}. The paper-marker table shows the full displayed marker profiles; bold markers share a mapped gene ID with at least one other displayed profile. Graph edges and joint-table values are computed from the full deduplicated mapped marker profiles. Profile IDs and graph nodes are colored by source paper. The same profiles can be compared by cell type label similarity and by marker-gene-set overlap, where $J$ is the Jaccard similarity between two marker gene sets. Marker-graph edge width scales with $J$. Parenthesized values count unordered pairs among the displayed profiles. In this compact example, label edges are based on normalized label-string matches, whereas gene overlap is computed on mapped Ensembl IDs. The red outline marks partial marker-overlap relationships. The joint table summarizes the observed label-marker relationships and provides a conservative triage: exact labels with identical marker sets are likely the same cell type, different labels with no shared markers are likely different cell types, and the remaining cells require context to distinguish cell type from cell state, granularity, naming, extraction depth, or reporting differences.}
