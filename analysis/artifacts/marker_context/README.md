# Marker Context Artifacts

Generated by `analysis/build_marker_context_analysis.py`.

- `marker_context_records.tsv`: one row per included marker claim, with a deterministic normalized marker statement and co-reported label context.
- `paper_label_contexts.tsv`: one row per paper with its extracted label neighborhood.
- `label_co_report_pairs.tsv`: label-label co-reporting counts across papers.
- `label_context_summary.tsv`: recurring label summaries and top co-reported labels.
- `same_label_context_marker_overlap.tsv`: same-label paper pairs with marker-set and label-context overlap.
- `same_label_context_marker_overlap_summary.tsv`: marker overlap stratified by context overlap.
- `label_ambiguity_summary.tsv`: recurring labels with marker union/intersection and pairwise marker overlap.
- `marker_ambiguity_summary.tsv`: markers reported for multiple labels.
- `marker_statement_normalization_prompt.md`: prompt template for an optional LLM pass over `marker_context_records.tsv`.

## LLM normalized context statements

The validated LLM-generated marker context statements are stored as:

- `llmarkers_context_statement_llm_records.tsv.gz`: compressed, GitHub-safe table with one validated marker context record per row.
- `llmarkers_context_statement_llm_summary.tsv`: validation summary.
- `llmarkers_context_statement_llm_failures.tsv`: failed records; expected to be empty for the current run.
- `llmarkers_context_statement_llm_report.md`: validation report.
- `llmarkers_context_statement_prompt.md`: prompt used to generate normalized statements.

The uncompressed `llmarkers_context_statement_llm_records.tsv`, per-shard
inputs/outputs, OpenAI batch request JSONL, and embedding matrices are local
scratch or regenerated artifacts and are intentionally ignored by git.

Run the embedding/context investigation from the compressed validated table:

```bash
uv run --locked python analysis/build_llmarkers_context_embedding_analysis.py \
  --provider minilm \
  --output-prefix llmarkers_context

uv run --locked python analysis/investigate_marker_context_claims.py \
  --input-prefix llmarkers_context
```

For OpenAI embeddings on a machine with sufficient disk, create a local `.env`
with `OPENAI_API_KEY=...` and run:

```bash
uv run --locked python analysis/build_llmarkers_context_embedding_analysis.py \
  --provider openai \
  --model text-embedding-3-large \
  --batch-size 128 \
  --output-prefix llmarkers_context_openai_large
```
