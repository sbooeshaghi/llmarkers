# Paper Workspaces

This directory separates the active manuscript from venue-specific submission packages.

- `biorxiv/`: active main-paper workspace for the LLMarkers manuscript, including the LaTeX sources, supplementary note, references, figure manifest, and paper-specific notes.
- `submissions/`: destination for journal- or venue-specific submission packages. Each submitted location should get its own folder here.

Obsolete presubmission-inquiry material is intentionally not kept here.
