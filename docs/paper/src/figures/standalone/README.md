# Standalone Paper Figures

These files render paper figures independently from `main.tex` for posters,
slides, and quick inspection.

Run from the repository root:

```sh
bash analysis/scripts/render_paper_standalone_figures.sh
```

Outputs are written to:

```text
docs/paper/src/figures/standalone/build/
```

The wrappers are intentionally thin. Figure 1 imports the shared TikZ body used
by the manuscript. The other wrappers import the figure PDFs generated by the
analysis scripts in `analysis/`.
