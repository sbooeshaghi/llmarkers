  \caption{\textbf{Stable identifiers connect marker evidence across papers, but reported marker panels remain variable.} The analysis combines mapped positive marker genes reported for one cell type in one paper and requires at least three genes. \textbf{A}. Fraction of cross-paper marker-panel pairs that share at least one marker. The first two bars separate exact-label links by whether both panels have the same accepted identifier. The third bar contains pairs connected only by an accepted identifier because their labels differ. The fourth is a matched different-identifier control. Numbers below the first three bars give the available observed links. For each identifier-only pair, reference and control pairs were matched by corpus collection and marker-panel size. Whiskers show 95\% intervals from 1{,}000 pair-bootstrap and matched-sampling replicates. \textbf{B}. Marker-panel Jaccard versus co-reported-label Jaccard for all 10{,}437 cross-paper pairs that use the same normalized target label. Each point is one paper pair. The red line is an ordinary least-squares fit, and the band is a 95\% interval from 1{,}000 bootstrap replicates that resampled normalized target labels as clusters. The target label was removed before co-reported-label Jaccard was calculated. \textbf{C}. Fraction of a fixed cohort of 37 normalized cell type labels retaining at least one marker in the intersection as paper-level panels are accumulated. Points are means from 1{,}000 replicates that resampled labels and randomly ordered panels; the band spans the 2.5th--97.5th percentiles.}
